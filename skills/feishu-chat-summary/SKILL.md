# 飞书聊天记录总结

## 工作流程

### 1. 获取聊天记录

使用 `feishu_im_user_search_messages` 工具搜索今天的消息：

- `relative_time: "today"` — 获取今天的所有消息
- `sender_type: "all"` — 获取所有类型的消息
- 分页获取所有消息（每页 50 条）

### 2. 分析消息内容

按聊天会话分组，识别：

- 重要讨论主题与关键决策
- @用户的消息

### 3. 提取待办事项

从消息中提取包含以下信号的内容：

- 关键词：「需要」「要」「记得」「别忘了」
- 被 @ 的任务分配
- 会议邀请、日程安排、截止日期

### 4. 生成总结报告

使用以下模板：

```markdown
# 📋 今日飞书聊天总结（YYYY-MM-DD）

## 🔥 重要讨论（X 个会话）

### 1. [群聊/单聊名称]
**关键内容：**
- 内容摘要

**重要决策：**
- 决策事项

---

## ✅ 待办事项（X 项）

| 优先级 | 事项 | 来源 | 截止时间 |
|--------|------|------|----------|
| ⚡ 紧急 | [任务内容] | [来源] | [时间] |
| 高 | [任务内容] | [来源] | [时间] |
| 中 | [任务内容] | [来源] | [时间] |
| 低 | [任务内容] | [来源] | [时间] |

---

## 📌 其他重要信息
- 信息项 1

---

*生成时间：YYYY-MM-DD HH:MM*
```

待办事项按优先级排序：⚡ 紧急 > 高 > 中 > 低。

### 5. 创建云文档

使用 `feishu_create_doc` 创建文档：

- 标题格式：`飞书聊天总结_YYYY-MM-DD`
- 将生成的 Markdown 内容传入
- 记录返回的 `doc_url`

### 6. 发送文档链接

使用 `feishu_im_user_message` 发送以下消息：

```
📋 今日飞书聊天总结已生成

📄 文档链接：[点击查看]

🔥 共 X 个重要讨论
✅ 共 X 项待办事项

简要预览：
- 最紧急的待办：[事项内容]
- 重要会议/安排：[内容]
```

## 注意事项

- 消息过多时，优先处理被 @ 的消息和群聊消息
- 不在总结中泄露敏感信息
