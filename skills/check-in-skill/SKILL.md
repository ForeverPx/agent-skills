# Checkin Skill - 打卡管理

## Description
管理每周打卡记录，包括健身、吉他练习、吃维生素。记录存储在 `my-ai-memory` 项目中，自动同步到 GitHub。

## Configuration
- **Repo Path**: `/root/clawd/codes/my-ai-memory`
- **Checkin Data**: `memos/checkin.md` (打卡记录)
- **Weekly Goals**: 健身 3 次、吉他练习 5 次、维生素 5 次、博客 4 次

## Usage

### 1. Analyze Intent
当用户说"打卡"时，分析用户要打卡的项目。支持的关键词：
- 健身相关：健身、锻炼、练背、练胸、跑步等
- 吉他相关：吉他、练吉他、弹吉他等
- 维生素相关：维生素、吃药、补充剂等

如果用户说"打卡健身"或"打卡：健身"，则记录为健身打卡。

### 2. Checkin Data Format

打卡记录文件 `memos/checkin.md` 格式：
```markdown
# 每周打卡记录

## 2026-W08 (2026-02-17 to 2026-02-23)
- [x] 健身 2026-02-17 10:00
- [x] 吉他 2026-02-17 14:30
- [x] 维生素 2026-02-17 08:00
- [ ] 健身
- [ ] 吉他
...
```

### 3. Handle Actions

#### A. 用户说"打卡 <项目>"
**步骤：**
1. 读取 `memos/checkin.md`
2. 找到当前周的记录（格式：`## YYYY-WXX (YYYY-MM-DD to YYYY-MM-DD)`）
3. 添加打卡记录：`- [x] <项目> <日期> <时间>`
4. 写回文件
5. Git 同步

**示例：**
用户说"打卡健身" → 添加 `- [x] 健身 2026-02-25 21:00`

#### B. 每天早上 9 点提醒
**触发：** Cron job 每天 09:00 CST
**步骤：**
1. 读取 `memos/checkin.md`
2. 找到当前周的记录
3. 统计本周各项目已完成次数
4. 计算剩余次数
5. 发送提醒到 Discord DM (ID: 1470416039685656762)
6. 根据打卡情况添加反馈：
   - **点赞/鼓励**：完成进度良好（≥50% 或按时间进度）
   - **提醒**：进度一般
   - **严厉批评**：快到周末（周六或周日）且剩余次数还很多（>50% 未完成）

#### C. 周一早上 9 点总结
**触发：** Cron job 每周一 09:00 CST
**步骤：**
1. 读取 `memos/checkin.md`
2. 找到上周的记录
3. 统计上周各项目完成情况
4. 生成总结报告（完成率、是否达标）
5. 发送到 Discord DM (ID: 1470416039685656762)
6. Git 同步

### 4. Git Sync (Mandatory)
每次修改后：
```bash
cd /root/clawd/codes/my-ai-memory
git add memos/checkin.md
git commit -m "Update checkin records"
git push
```

### 5. Week Calculation

计算当前周的 ISO 周数和日期范围：
- 周一是每周的第一天
- 格式：`2026-W08 (2026-02-17 to 2026-02-23)`
- 可以用命令获取：`date -d "2026-02-25" "+%Y-W%V"` → `2026-W08`
