# Agent Skills

一个用于扩展 AI 助手能力的 **Skill 合集**。通过结构化的 `SKILL.md` 文件，告诉 AI 在特定场景下该做什么、怎么做，让 AI 从「问答工具」变成「主动执行的助手」。

---

## 核心理念

与其反复告诉 AI「帮我做 XX」，不如一次性把规则写清楚：什么触发条件、读写哪个文件、发什么通知、返回什么格式——这就是 Agent Skill 的本质。

一个 Skill 由三部分组成：

```
skill-name/
├── SKILL.md          # AI 的行为规范（核心）
├── script.py         # 辅助脚本（可选）
└── setup.py          # 初始化/定时任务脚本（可选）
```

数据持久化方案：所有 Skill 共用一个私有 Git 仓库（`my-ai-memory`）存储结构化 Markdown 文件，AI 读写后自动 `git push` 同步。

## Skills 列表

### [check-in-skill](./skills/check-in-skill/) — 习惯打卡管理

> 一句话打卡，AI 自动记录、提醒、汇报。

健完身跟 AI 说「打卡健身」，它会记录时间戳、更新进度，并同步到 GitHub。每天早上 9 点主动推送 Discord 提醒，周一发上周总结。不需要打开任何 App。

**追踪的习惯：**

| 习惯 | 每周目标 |
|------|----------|
| 健身 | 3 次 |
| 吉他练习 | 5 次 |
| 吃维生素 | 5 次 |
| 写博客 | 4 篇 |

**示例交互：**

```
用户：打卡健身

AI：✅ 已记录：健身 2026-03-03 21:00

今天又变强了一点！继续加油！✨

本周进度：
- 健身：2/3 次 ⏳
- 吉他：3/5 次 ⏳
- 维生素：5/5 次 ✅
- 博客：1/4 篇 ⏳
```

周末进度落后时，AI 会切换成「严厉模式」催促：

```
⚠️ 今天是周六，你还有周日一天时间！别再拖了！🔥
```

**文件结构：** `my-ai-memory/memos/checkin.md`

### [todo-manage](./skills/todo-manage/) — 待办事项管理

> 自然语言增删改查待办，数据同步 Git。

直接跟 AI 说「待办 下周三前提交报告」，它会自动推断分类（工作/生活）、打上合适的标签，写入文件并同步。

**支持的操作：**

| 操作 | 触发词 | 示例 |
|------|--------|------|
| 添加 | `todo` / `待办` | `待办 周三前提交代码审查` |
| 完成 | `完成` / `finish` | `完成 代码审查` |
| 列表 | `待办列表` / `list todos` | 按分类展示所有任务 |
| 搜索 | `待办搜索 #标签` | `待办搜索 #开发` |

**自动标签推断规则（部分）：**

| 标签 | 触发关键词 |
|------|-----------|
| `#会议` | 会议、开会、讨论 |
| `#开发` | 开发、代码、接口、API |
| `#AI` | AI、模型、LLM |
| `#部署` | 部署、上线、配置 |
| `#财务` | 费用、账单、付款 |

**文件结构：** `my-ai-memory/memos/todo.md`

## 技术架构

```
AI 助手（运行在服务器）
    │
    ├── 读取 SKILL.md       → 知道「什么时候做什么」
    ├── 调用 Python 脚本     → 处理复杂逻辑（统计、格式化）
    ├── 读写 my-ai-memory/  → Markdown 文件作为轻量数据库
    ├── git add/commit/push → 数据自动同步到 GitHub
    └── 发送 Discord 消息   → 主动通知（打卡确认、每日提醒）
         │
         └── cron jobs      → 定时触发（每日 9 点、每周一）
```

**为什么用 Git 存数据？**

- **透明可查**：每次打卡都有精确时间戳，随时翻历史
- **数据自主**：存在自己的仓库，不依赖任何第三方平台
- **可扩展**：Markdown 纯文本，后续可以写脚本做统计分析

## 如何使用

### 前置条件

- 一台运行 AI 助手的服务器（支持调用 shell 命令和 Python 脚本）
- 一个私有 Git 仓库用于存储数据（本项目中为 `my-ai-memory`）
- Discord Bot Token（用于主动推送通知，可选）
- cron 权限（用于定时任务，可选）

### 接入 Skill

1. Clone 本仓库：

   ```bash
   git clone https://github.com/panxiao81/agent-skills.git
   ```

2. 将目标 Skill 目录复制到你的 AI 助手的 skills 目录下。

3. 按照 `SKILL.md` 中的 `## Configuration` 部分，修改仓库路径、Discord 配置等为你自己的值。

4. 如果 Skill 包含 Python 脚本，安装依赖后将脚本部署到服务器。

5. 如果需要定时任务，参考 Skill 文档配置 cron job。

## 如何创建自己的 Skill

一个好的 `SKILL.md` 应该包含以下几个部分：

```markdown
# Skill 名称

## Description
一句话说明这个 Skill 的作用，以及何时触发。

## Configuration
- 数据文件路径
- 外部服务配置（API Key、Webhook URL 等）

## File Format
数据文件的具体格式说明（如有）。

## Usage
### 1. 意图识别
触发条件和关键词列表。

### 2. 操作流程
每种操作的具体执行步骤（读哪个文件、怎么修改、怎么回复）。

### 3. 同步
数据修改后的持久化步骤。

### 4. 回复格式
AI 回复用户的标准格式示例。
```

核心原则：**把所有模糊的地方写清楚**。AI 按规范执行，规范写得越清晰，行为就越稳定。
